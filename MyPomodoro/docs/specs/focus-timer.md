# 집중 타이머 (Pomodoro)

[← 목차](./README.md)

## 기능 설명

뽀모도로 방식의 집중·휴식 타이머를 제공한다. 기본값은 집중 25분, 휴식 5분이며, 사용자는 타이머를 시작·일시정지·재개·중단할 수 있다. 집중 세션이 완료되면 휴식 타이머로 자동 전환되고, 휴식이 끝나면 다음 집중 세션을 시작할 수 있다.

## 사용자 행동

1. **Timer** 탭에서 현재 모드(집중/휴식)와 남은 시간을 확인한다.
2. **시작** 버튼을 눌러 타이머를 시작한다.
3. 실행 중 **일시정지** 또는 **재개**를 눌러 타이머를 제어한다.
4. 집중 세션 완료 시 알림(또는 화면 전환)을 확인하고 휴식 타이머로 넘어간다.
5. 휴식 완료 후 다음 집중 세션을 시작하거나 중단한다.
6. 필요 시 **중단** 버튼으로 현재 세션을 종료한다.

## 입력값

| 항목 | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| `focusDuration` | `TimeInterval` | 25분 (1,500초) | 집중 세션 길이 |
| `breakDuration` | `TimeInterval` | 5분 (300초) | 휴식 세션 길이 |
| `timerAction` | `enum` | — | `start` / `pause` / `resume` / `stop` |
| `currentMode` | `enum` | `focus` | `focus` / `break` |

## 저장 데이터

타이머 실행 중에는 메모리(뷰모델) 상태만 유지한다. 세션이 **완료**되거나 **중단**될 때 `StudySession`으로 저장한다([공부 시간 저장](./study-session-storage.md) 참고).

| 필드 | 설명 |
|------|------|
| `timerState` (런타임) | `idle` / `running` / `paused` |
| `remainingSeconds` (런타임) | 현재 남은 시간 |
| `sessionStartAt` (런타임) | 현재 세션 시작 시각 |

## 예외 상황

| 상황 | 처리 |
|------|------|
| 앱이 백그라운드로 전환됨 | 타이머는 백그라운드에서 계속 진행. 복귀 시 남은 시간을 `sessionStartAt` 기준으로 재계산 |
| 앱이 강제 종료됨 | 진행 중 세션은 저장하지 않음. 재실행 시 타이머는 `idle` 상태 |
| 집중 세션 중 **중단** | 완료되지 않은 세션은 `StudySession`에 저장하지 않음(또는 `isCompleted: false`로 부분 저장 — MVP에서는 미저장 권장) |
| 휴식 중 **중단** | 휴식 시간은 통계에 포함하지 않음 |
| 집중 시간이 0초 이하로 설정됨 | 시작 버튼 비활성화, 오류 메시지 표시 |
| 타이머 실행 중 과목 미선택 | 시작 전 과목 선택을 요구하거나, 기본 과목(마지막 선택) 자동 적용 |
