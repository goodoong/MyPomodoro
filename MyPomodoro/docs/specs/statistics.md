# 기본 통계

[← 목차](./README.md)

## 기능 설명

저장된 `StudySession`을 집계하여 일별·주별 공부 시간과 과목별 비율을 보여준다. **Statistics** 탭에서 차트·숫자로 확인하고, **Home** 탭에서는 오늘 요약을 제공한다.

## 사용자 행동

1. **Statistics** 탭에서 오늘/이번 주 공부 시간을 확인한다.
2. 과목별 분포(막대 또는 원형 차트)를 확인한다.
3. **Home** 탭에서 오늘 목표 대비 진행률을 확인한다(일일 목표 설정 시).
4. 데이터가 없는 기간에는 빈 상태 UI를 확인한다.

## 입력값

| 항목 | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| `dateRange` | `enum` | `today` | `today` / `thisWeek` |
| `referenceDate` | `Date` | 오늘 | 집계 기준일 |
| `dailyGoalMinutes` | `Int` | 120 | 일일 목표(분) — Settings에서 변경 |

## 저장 데이터

**집계는 저장하지 않고 런타임 계산.** 원천 데이터는 `StudySession`.

**모델: `DailyGoal` (선택, Home 진행률용)**

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | `UUID` | 고유 식별자 |
| `targetMinutes` | `Int` | 일일 목표 시간(분) |
| `updatedAt` | `Date` | 마지막 수정 시각 |

**표시 지표 (계산값)**

| 지표 | 계산 방식 |
|------|-----------|
| 일별 공부 시간 | 당일 `StudySession.durationSeconds` 합계 |
| 주별 공부 시간 | 해당 주(월~일) `StudySession.durationSeconds` 합계 |
| 과목별 분포 | 기간 내 `subjectId`별 `durationSeconds` 합계 및 비율(%) |
| 목표 달성률 | `일별 공부 시간 / dailyGoalMinutes × 100` |

## 예외 상황

| 상황 | 처리 |
|------|------|
| 해당 기간 세션 0건 | "아직 기록이 없습니다" 빈 상태 + Timer 시작 유도 |
| 삭제된 과목의 세션 | "알 수 없는 과목" 또는 원래 이름 스냅샷으로 표시 |
| 목표 시간 0분 | 달성률 표시 생략 또는 "목표를 설정하세요" 안내 |
| 타임존 변경 | `Calendar.current` 기준 로컬 날짜로 집계 |
| 미래 날짜 조회 | 빈 결과 반환 |
