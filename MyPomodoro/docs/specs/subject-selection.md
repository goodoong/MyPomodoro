# 과목 선택

[← 목차](./README.md)

## 기능 설명

사용자가 공부 과목(예: 수학, 영어, 개발)을 등록·선택하여 타이머 세션과 통계를 과목별로 구분한다. Timer 탭에서 현재 세션에 적용할 과목을 선택하고, Settings에서 과목을 추가·수정·삭제할 수 있다.

## 사용자 행동

1. **Timer** 탭에서 과목 목록(또는 피커)을 열고 공부할 과목을 선택한다.
2. **Settings** 탭에서 **과목 추가**를 눌러 새 과목 이름을 입력한다.
3. 기존 과목 이름을 수정하거나 삭제한다.
4. 선택한 과목으로 타이머를 시작한다.

## 입력값

| 항목 | 타입 | 제약 | 설명 |
|------|------|------|------|
| `name` | `String` | 1~30자, 공백만 불가 | 과목 이름 |
| `color` | `Color` (선택) | — | 과목 구분용 색상 (MVP: 프리셋 6색 중 선택) |
| `selectedSubjectId` | `UUID` | 존재하는 과목 ID | 타이머에 연결할 과목 |

## 저장 데이터

**모델: `Subject`**

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | `UUID` | 고유 식별자 |
| `name` | `String` | 과목 이름 |
| `colorHex` | `String` | 표시 색상 (선택) |
| `createdAt` | `Date` | 생성 시각 |
| `sortOrder` | `Int` | 목록 정렬 순서 |

**런타임 상태**

| 필드 | 설명 |
|------|------|
| `lastSelectedSubjectId` | UserDefaults 등에 마지막 선택 과목 저장 |

## 예외 상황

| 상황 | 처리 |
|------|------|
| 과목 이름이 비어 있음 | 저장 버튼 비활성화 |
| 동일 이름 과목이 이미 존재 | "이미 존재하는 과목입니다" 안내, 저장 차단 |
| 등록된 과목이 0개 | Timer 탭에 "과목을 먼저 추가하세요" 안내, Settings로 이동 유도 |
| 과목 삭제 시 연결된 `StudySession` 존재 | 삭제 확인 다이얼로그 표시. 삭제 시 세션의 `subjectId`는 유지하되 과목은 soft-delete 또는 "삭제된 과목"으로 표시 |
| 타이머 실행 중 과목 변경 | 변경 불가. 일시정지 또는 세션 종료 후 변경 가능 |
