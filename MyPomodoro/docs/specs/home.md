# 홈 (Home)

[← 목차](./README.md)

## 기능 설명

앱 진입 시 오늘의 공부 요약(총 시간, 완료 세션 수, 목표 달성률)과 빠른 타이머 시작 진입점을 제공한다.

## 사용자 행동

1. 앱 실행 후 **Home** 탭에서 오늘 공부 현황을 확인한다.
2. **타이머 시작** 버튼을 눌러 Timer 탭으로 이동한다.
3. 최근 사용 과목을 빠르게 선택해 타이머를 시작한다(MVP: 마지막 선택 과목 표시).

## 입력값

| 항목 | 타입 | 설명 |
|------|------|------|
| `referenceDate` | `Date` | 오늘 (로컬 캘린더) |

## 저장 데이터

저장 없음. `StudySession`, `DailyGoal`, `Subject`를 읽어 표시만 한다.

## 예외 상황

| 상황 | 처리 |
|------|------|
| 오늘 기록 없음 | 0분, 0세션, "오늘 첫 공부를 시작해 보세요" 표시 |
| 목표 미설정 | 기본값 120분 적용 또는 Settings 유도 |
